# Git 협업 연습 프로젝트

Git과 GitHub를 활용한 팀 협업 연습 프로젝트입니다

## 프로젝트 소개

Git의 기본 명령어와 브랜치 관리, Pull Request를 연습합니다

## 주요 학습 내용

Git 기본 명령어

## 브랜치 생성 및 관리

Commit 및 Push

Pull Request와 코드 리뷰

Merge를 통한 협업

## 작업 순서

저장소 Clone

작업 브랜치 생성

파일 수정 및 Commit

GitHub에 Push

Pull Request 생성

코드 리뷰 후 main에 병합

## 팀 협업 규칙

main 브랜치에 직접 Push하지 않기

작업별로 브랜치 생성하기

커밋 메시지는 변경 내용을 명확하게 작성하기

PR을 통해 코드 리뷰 진행하기

# 프로젝트 목적

GitHub-flow를 익히고 팀원들과 협업하는 방법을 연습합니다
